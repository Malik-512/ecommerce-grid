\# ShopEase — Responsive E-Commerce Product Gallery



\## Lab 8 — Web Engineering (CSS Grid + Git/GitHub)



\### Features

\- Auto-responsive product grid using `repeat(auto-fit, minmax(250px, 1fr))`

\- No explicit media queries — layout adapts fluidly to viewport width

\- Card hover animations (lift, shadow, icon tilt)

\- Clean header, gallery, and footer layout



\### Files

| File | Purpose |

|------|---------|

| `index.html` | Product gallery markup |

| `style.css` | Grid layout, card styling, hover animations |

| `README.md`  | Project documentation |



\### How to run

Open `index.html` in any modern browser — no build step required.
